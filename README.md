# Mahabharata Family Tree

Interactive family tree of 389 figures from the Mahabharata, with parent role labels.

Live: https://vijaymd44-ops.github.io/mahabharata-tree/

## Portraits
51 major characters have painted portraits (classical Indian epic style, AI-generated) in `portraits/`. Everyone else shows a round placeholder with their initials, tinted by gender (blue-grey male, rose female, neutral unknown; "?" for placeholder persons).
